`docker.svg`: uma baleia com os contêineres nas costas, desenhada à mão pra este plugin
(não é o logo oficial). Docker é marca da Docker, Inc.; o desenho aqui só identifica o plugin.

Os avatares da lista não são arquivos: o `icons.js` gera o SVG na cor de cada um — um
contêiner de navio em isométrico pra cada container, e uma pilha de três pra cada projeto
do compose. A cor é a da imagem (ou do nome do projeto) até você escolher outra no botão
direito, em "Cor"; a escolha fica no `state.json` do plugin.
